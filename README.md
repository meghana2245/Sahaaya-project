# 💛 Sahaaya

Sahaaya is a community-driven emotional support and volunteer matching system built using Streamlit and SQLite.

## 🌍 Features

- 📝 Mood Check-in with emotional severity tracking
- 📊 Community Emotional Dashboard
- 👥 Local Support Circle
- 🤝 Volunteer Registration & Matching
- 📅 Community Events Hub
- 🌈 Recovery Stories with Admin Approval
- 💬 Comment & Engagement System
- 💾 Persistent SQLite Database

## 🛠 Tech Stack

- Python
- Streamlit
- SQLite
- Pandas
- Matplotlib

## 🚀 Deployment

Deployed using Render with persistent SQLite backend.

## 🎯 Purpose

Sahaaya aims to reduce urban loneliness by creating structured emotional support systems within local communities.
